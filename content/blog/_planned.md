## Rules for every post

- 100% original writing. Never copy or paraphrase a competitor article.
- 1,500–2,500 words. Opening paragraph = a 40–60 word direct answer to the title.
- Structure: answer → TL;DR → table of contents (automatic) → H2s phrased as
  real questions → a checklist or table → "How Zyverra helps" → 4–6 FAQs →
  sources → CTA (free audit + WhatsApp).
- At least 3 credible, linked sources from `src/data/blog/sources.ts` (add new
  ones there only after checking the URL resolves). No unsourced statistics.
- One original element: worked example, checklist, comparison table or
  step-by-step with screenshot placeholders.
- Internal links: 2+ service pages, 2+ other posts, pricing.
- ASA-safe: no prescription-only medicine brand names promotionally (only the
  compliance post explains the rule).
- Title ≤60 chars, meta ≤155 chars, one main keyword not used by any other post
  or page (check before writing).
